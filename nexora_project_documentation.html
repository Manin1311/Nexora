Project Introduction

What is Nexora?

Nexora is a next-generation, AI-powered engineering skills platform designed to take developers from beginner to industry-ready through structured learning, real-time challenges, mock interviews, and live multiplayer coding battles.

🎯 Problem Statement: Aspiring software developers face a fragmented ecosystem — they need LeetCode for challenges, HackerRank for assessments, LinkedIn for portfolios, YouTube for learning, and separate tools for interview preparation. Nexora unifies the entire developer journey into one cohesive, AI-driven platform.

The Landing Page is the public-facing marketing homepage of Nexora. It is a premium, fully animated single-page experience that communicates the platform's value proposition, showcases core features, displays AI-generated testimonials, and converts visitors into registered users.

What It Does

Creates the first impression using glassmorphism cards, parallax gradient backgrounds, an animated particle system, and smooth scroll-triggered Framer Motion stagger animations for feature reveal.

Key Features

⚡ Hero Section
Full-viewport hero with gradient text, floating badge system, and CSS keyframe particle background.
🎯 Feature Showcase
Glassmorphic feature cards for all 9 core platform modules with scroll reveal animations.
🤖 AI Demo Section
Live character-by-character typing animation showing AI challenge generation directly on the page.
📊 Stats Counter
Animated number counters (0 to target) triggered on scroll entry using Intersection Observer API.
🌙 Dark/Light Mode
Full theme system via CSS custom properties. Toggle state persisted in localStorage.
📱 Fully Responsive
Mobile-first responsive design with collapsible navbar and fluid grid layouts.

Code Logic — Animated Counter

JSX / React // Animated Counter: counts from 0 to target on scroll entry const useCounter = (target, duration = 2000) => { const [count, setCount] = useState(0) const ref = useRef() useEffect(() => { const observer = new IntersectionObserver(([entry]) => { if (entry.isIntersecting) { let start = 0 const step = (target / duration) * 16 const timer = setInterval(() => { start = Math.min(start + step, target) setCount(Math.round(start)) if (start >= target) clearInterval(timer) }, 16) } }) if (ref.current) observer.observe(ref.current) return () => observer.disconnect() }, []) return { count, ref } }

Page 02
Authentication — Login & Register
/login  |  /register
JWT Auth Google OAuth Secure Token Rotation

Nexora uses a dual-token JWT system with Google One-Tap OAuth as an alternative. Access tokens expire in 60 minutes and are silently refreshed using refresh tokens (7-day lifetime). Registration includes a mandatory terms agreement checkbox and a live password strength meter.

Key Features

🔑 JWT Dual-Token
Access (60 min) + Refresh (7 days). Axios interceptor auto-refreshes silently. Tokens blacklisted on logout.
🌐 Google One-Tap
GSI library renders native Google button. Backend verifies ID token and issues JWT pair.
✅ Terms Checkbox
Mandatory checkbox linking to full Terms and Privacy Policy pages. Submit disabled until checked.
🛡️ Password Strength
Real-time color-coded meter (Weak → Very Strong) using regex validation scoring.

🎤 How to Present This Page to Faculty

  • Click Sign In with Google — show the native Google One-Tap popup appearing.
  • Show the Register form with the live password strength meter changing colors as you type.
  • Demonstrate the Terms & Privacy links opening dedicated policy pages.
  • Say: "Authentication uses industry-standard JWT with silent auto-refresh — users are never logged out unexpectedly."

Code Arena — Live 1v1 Multiplayer Battle

WebSockets Real-Time 1v1 Battle Anti-Cheat

The Code Arena is a real-time multiplayer competitive coding platform where two developers battle head-to-head simultaneously. Built on Django Channels + ASGI WebSockets with socket-level JWT auth.

Speed MCQ rounds, 30 seconds per question. Points awarded for speed + accuracy.

🛡️ Anti-Cheat Engine
Tab-blur detection. 3 violations = automatic disqualification and session flagging.
