What is Nexora?

🎯 The Problem We Solve

Developers use 5–8 different platforms to practice coding (LeetCode), prepare for interviews (Pramp), manage portfolios (GitHub), get code feedback, and learn from mentors. This fragmentation wastes time, lacks continuity, and provides zero AI-driven personalization. Nexora consolidates all of this into one intelligent platform.

💡 Our Solution

Nexora is a full-stack, AI-powered developer growth platform built with Django REST Framework + React + PostgreSQL. It provides personalized coding challenges, AI-powered mock interviews with real-time behavior analysis, adaptive learning roadmaps, AI mentor chatbot, GitHub code health analysis, peer code reviews, resume builder with ATS scoring, and live 1v1 coding battles — all under one roof with a unified XP/rank progression system.

What Makes Nexora Unique?
1

Unified XP & Rank Ecosystem

Every action across ALL modules contributes to a single XP pool with 5 developer ranks (Explorer → Legend). Gamification drives continuous engagement unlike siloed platforms.

2

AI Memory Engine — Cross-Module Persistent Context

The UserAIMemory model tracks skills mastery, weaknesses, recurring mistakes, interview stats, and career goals across ALL 10 modules. Every AI response is personalized using this memory.

3

Multi-Model AI with Automatic Fallback

Primary: Groq LLaMA 3.3 70B with multi-key load balancing. If all Groq keys are rate-limited → automatic fallback to Google Gemini 2.5 Flash (also with multiple API keys). Zero downtime AI.

4

Real-Time WebSocket Battleground

Code Arena uses Django Channels + Daphne ASGI for real-time WebSocket connections enabling live 1v1 coding battles with progress sync, battle state management, and instant winner detection.

5

Interview with Biometric Analysis

During mock interviews: captures webcam snapshots, analyzes posture & eye contact via AI vision, tracks filler words (um, uh, like), measures WPM, and generates behavioral feedback — beyond just answer quality.
