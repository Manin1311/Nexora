Frontend — React Architecture

🎨 Frontend Deep Dive

React 18 + Vite + Framer Motion — a modern, performance-optimized SPA with glassmorphism design, 24 pages, animated transitions, real-time WebSocket integration, and a rich design system built entirely in Vanilla CSS.

Frontend Technology Stack

📦 Core Dependencies & Why

  • React 18 — Component-based UI. Hooks (useState, useEffect, useRef, useContext) replace class components. Concurrent rendering for smooth animations.
  • Vite — Build tool. 10x faster than CRA (Create React App). HMR (Hot Module Replacement) updates in <100ms. Production build with code-splitting and tree-shaking.
  • React Router v6 — Client-side routing. BrowserRouter + Routes + Route. Nested routes for interview session. ProtectedRoute wrapper for auth-gated pages.
  • Framer Motion — Production-grade animation library. Used for page transitions (AnimatePresence), button hover/tap effects (whileHover, whileTap), staggered list animations, modal entrance/exit.
  • Axios — HTTP client. Configured with base URL + interceptor that auto-attaches JWT from localStorage and handles 401 → token refresh flow.
  • Monaco Editor — VS Code's editor embedded in browser. Used in Code Arena for the coding battle editor with syntax highlighting, IntelliSense for 40+ languages.
  • Vanilla CSS — No Tailwind, no CSS-in-JS. All styles in index.css using CSS Custom Properties (variables) for the design system. Glassmorphism, dark mode, smooth gradients.

📁 Project Structure

  • src/App.jsx — Root component. Sets up BrowserRouter, AuthProvider context, route definitions, ProtectedRoute/GuestGuard wrappers, Sidebar vs LandingNavbar logic.
  • src/pages/ — 24 page components. Each page = one feature module. All pages use inline styles for component-level specificity.
  • src/components/ — Reusable components: layout/Sidebar, layout/LandingNavbar, ui/CommandPalette, ui/GuidedTour.
  • src/context/ — AuthContext.jsx — React Context providing user, isAuthenticated, login(), logout() globally.
  • src/services/ — API service modules: authService.js, challengeService.js, interviewService.js etc. Abstracts all Axios calls.
  • src/utils/ — Utility functions: date formatting, XP calculations, localStorage helpers.
  • src/index.css — 12KB design system with CSS variables, animations, glassmorphism classes, scrollbar styles.

Key Components — Deep Explanation
src/App.jsxRoot Component — Routing Hub
  • AuthProvider wraps everything — useAuth() hook available in any child component. Provides user, isAuthenticated, login(token), logout().
  • ProtectedRoute — HOC that checks isAuthenticated. If not authenticated → saves current URL to sessionStorage → redirects to /login. After login, restores the saved URL.
  • GuestGuard — Redirects authenticated users away from public-only pages (landing) to app pages. Prevents logged-in users from seeing the marketing page.
  • Layout switching — Public pages (/, /about, /privacy, /terms, /contact) get LandingNavbar + Footer. App pages (all others) get the Sidebar. This is determined by isPublicPage boolean.
  • AnimatePresence — Framer Motion wrapper around Routes. Enables exit animations when navigating between pages. Each page fades/slides in and out smoothly.
  • CommandPalette — Global Cmd+K shortcut palette. Allows quick navigation to any page by typing, visible from anywhere in the app.
InterviewSessionPage.jsxMost Complex Page — 76KB, 1456 lines
  • Webcam + Audio setup — navigator.mediaDevices.getUserMedia({video, audio}). Video stream attached to <video ref>. Fallback to audio-only if webcam fails (Zoom/OBS conflicts).
  • Audio Visualizer — Web Audio API: creates AudioContext → AnalyserNode → connects mic stream. Reads frequency data each frame via requestAnimationFrame and draws a waveform on <canvas>.
  • Speech Recognition — window.SpeechRecognition (Web Speech API). Set continuous=true, interimResults=true. Fixed duplicate bug: committedTextRef tracks finalized text separately from interim preview, preventing "hello hello hello" bug.
  • Filler Word Detection — On each final recognition result, counts occurrences of ["um", "uh", "like", "you know", "basically", "actually", "literally"] in the transcript. Displays live count.
  • WPM Calculation — Records startTimeRef.current = Date.now() on first word spoken. On submit: wpm = (wordCount / elapsedMinutes). Shown in feedback panel.
  • Webcam Snapshot — On answer submit, draws current video frame to a <canvas> (320×240px, mirrored to match display), converts to base64 JPEG (0.6 quality), sends to backend as image_frame field for AI body language analysis.
  • Boardroom Mode TTS — Uses window.speechSynthesis to speak AI panelist responses aloud. Different voice rate/pitch for Tech Lead, Architect, and HR Manager characters.
context/AuthContext.jsxGlobal Authentication State
  • Uses React createContext + useContext pattern. Wraps entire app in <AuthProvider>. Any component can call const { user, isAuthenticated, login, logout } = useAuth().
  • Persistent auth — On page load, reads JWT from localStorage. If token exists, calls /api/users/profile/ to verify token and populate user state. If 401 → auto-clears tokens → user stays logged out.
  • Axios interceptor — All Axios requests automatically have Authorization: Bearer token injected. 401 responses trigger refresh token flow transparently.
CodeArenaPage.jsxReal-time WebSocket Battle — 101KB, Largest File
  • WebSocket connection — new WebSocket('ws://…/ws/arena/{roomCode}/?token={JWT}'). JWT passed as query param since WS handshake cannot set custom headers like HTTP.
  • Message handling — ws.onmessage parses JSON events: room_state (initial room setup), player_joined (opponent connected), battle_start (countdown begins), progress_update (opponent's test progress), battle_finish (winner declared).
  • Monaco Editor integration — @monaco-editor/react. Language selector changes syntax highlighting. Real-time test execution against the challenge's test cases. Progress = tests_passed/total_tests * 100.
  • Heartbeat ping — Sends { type: "ping" } every 30 seconds to keep WebSocket alive through proxy timeouts.
Design System — index.css

🎨 CSS Custom Properties (Variables)

  • --glass-bg — rgba(255,255,255,0.05) for glassmorphism cards
  • --glass-border — rgba(255,255,255,0.08) for card borders
  • --accent — #6c63ff (primary brand purple)
  • --text-primary — #e2e8f0 (main text color)
  • --bg-primary — #0a0a0f (deep dark background)
  • All colors defined once, used everywhere — easy theme changes

✨ Visual Design Techniques

  • Glassmorphism — backdrop-filter: blur(20px) + semi-transparent backgrounds for card depth
  • Gradient Text — background-clip: text; -webkit-text-fill-color: transparent for colored headings
  • Framer Motion — whileHover={{ scale: 1.02 }} on every interactive button for micro-animations
  • Radial Gradients — Glowing orbs as decorative bg elements on hero sections
  • Custom Scrollbar — Thin purple scrollbar via ::webkit-scrollbar pseudo-elements
  • Stagger animations — List items animate in with 0.05s delay between each via Framer staggerChildren
Service Layer — API Abstraction

🔧 Why a Service Layer?

Instead of calling Axios directly in every component, all API calls are abstracted into src/services/ modules. This means: (1) changing the API URL happens in one place, (2) error handling is centralized, (3) components stay clean and readable, (4) easy to mock for testing. Each service module (challengeService.js, interviewService.js etc.) exports functions like getChallenges(params), submitChallenge(id, data) that components call directly.

1

Component calls service function

e.g. const data = await interviewService.submitAnswer(sessionId, questionId, payload)

2

Service calls Axios with correct endpoint

Axios interceptor auto-adds Authorization: Bearer <token> from localStorage

3

Response returned to component

Component updates state with returned data. Framer Motion re-renders with new content smoothly.

4

If 401 (token expired)

Axios response interceptor automatically hits /api/auth/token/refresh/, gets new token, retries the original request transparently.
